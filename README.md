# social-media
.

Finished UkasonDev post files only, served as raw links for Metricool and the Instagram publisher. No Actions, no Pages.

- `ig/ig-queue.json`: the Instagram publisher's post list (format: marketing/social/publisher/ig-queue.example.json in the project files). Written by the Marketer.
- `ig/`, `tiktok/`, `gmb/`: media, named `<post date>-<name>.<ext>`. JPEG images, MP4 videos under 50 MB.
- Each post's media is deleted 14 days after it goes out, to keep the repo small.
